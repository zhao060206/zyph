第一步 · 填入腾讯云密钥
这是让网站能上传照片的钥匙,只需要填一次。密钥保存在本机浏览器。管理活动和删除文件时会通过 HTTPS 发送到本站服务器校验，上传文件时会发送到腾讯云。
在哪找:登录腾讯云 → 右上角头像 → 访问管理 → API 密钥管理。
保存后浏览器可能弹出"记住密码",同意它,下次换设备或清了缓存就能一键带回。
